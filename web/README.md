# INDTV — אתר טלוויזיה לסמארט TV

אתר שמתנהג כמו אפליקציה, בנוי לשליטה מלאה בשלט (חיצים, OK, חזרה) בדפדפן של טלוויזיה חכמה
(Samsung Tizen, LG webOS, Android TV / Google TV, וגם מחשב).
ערוצים נטענים אוטומטית מרשימת הודו של iptv-org:

`https://iptv-org.github.io/iptv/countries/in.m3u` (שם המקור באתר: **India Built-in**)

## איך מעלים לאוויר (בלי שרת, בלי בנייה)

האתר הוא קבצים סטטיים בלבד. אין שלב build.

**הכי מהיר — Netlify Drop**
1. היכנסו ל-https://app.netlify.com/drop
2. גררו לשם את התיקייה `indtv-web` כולה.
3. תקבלו כתובת https. פתחו אותה בדפדפן של הטלוויזיה.

**GitHub Pages**
1. צרו ריפו חדש והעלו את תוכן התיקייה לשורש שלו.
2. Settings → Pages → Deploy from branch → `main` / root.

**בדיקה מקומית במחשב**
```
cd indtv-web
python3 -m http.server 8080
```
ואז http://localhost:8080 (לא לפתוח את index.html ישירות כקובץ — חלק מהדפדפנים חוסמים אז את הרשימה).

## שליטה בשלט

- תפריט עליון ותפריט צד: **מספיק לעבור עם החיצים** — המסך מתחלף מיד, בלי OK. הפוקוס נשאר על התפריט.
- כרטיסי ערוצים, Watch Live, הגדרות ותוצאות חיפוש: דורשים **OK**.
- בנגן: לחיצה ראשונה מציגה את הפקדים; חזרה ראשונה מסתירה אותם, השנייה יוצאת ממסך מלא, השלישית סוגרת את הנגן.
- ערוץ +/− בשלט (או PageUp/PageDown) מחליפים ערוץ בתוך הרשימה שממנה נפתח הנגן.
- מקשי מדיה (Play/Pause/Stop/FF/RW) נתמכים. קודי החזרה של Tizen (10009) ו-webOS (461) ממופים.

## מה יש בפנים

| תחום | איפה |
|---|---|
| פענוח M3U (tvg-id, tvg-name, tvg-logo, group-title, EXTVLCOPT), הבחנה בין רשימת ערוצים ל-HLS בודד | `js/data/m3u-parser.js` |
| Playlist / Channel / Favorites / Recent / Sources + איחוד כפילויות לערוץ אחד עם כמה מקורות | `js/data/repositories.js` |
| EPG (XMLTV) ו-VOD (סרטים, סדרות, המשך צפייה) | `js/data/epg-vod.js` |
| נגן יחיד: ביטול בקשה קודמת, מעבר למקור הבא, הגנה מערוץ "תקוע" | `js/player/player-controller.js` |
| ניווט D-pad | `js/ui/focus.js` |
| מסכים | `js/ui/screens/` |
| מטמון לוגואים ומעטפת האפליקציה (Service Worker) | `sw.js` |

- הלוגו של כל ערוץ הוא בדיוק הערך של `tvg-logo` מהרשימה, אותו URL בכל המסכים. כשאין לוגו או שהוא לא נטען מוצג גיבוי ממותג של INDTV (מונוגרמה + שם), לא לוגו מומצא.
- קטלוג הערוצים נשמר במכשיר (IndexedDB). בהפעלה הבאה מוצגים קודם הערוצים השמורים והרשימה מתרעננת ברקע. אם הרענון נכשל — הערוצים השמורים נשארים.
- מועדפים ונצפו לאחרונה נשמרים לפי זהות יציבה (tvg-id בלי סיומת ה-feed, אחרת שם מנורמל), כך שרענון לא מוחק אותם.
- אנגלית / עברית עם RTL מלא; הבחירה נשמרת.

## מגבלות שחשוב לדעת

- **שידורים ציבוריים לא תמיד עובדים.** חלק מהערוצים ברשימה יורדים, מסומנים `[Not 24/7]` או `[Geo-blocked]`. כשכל המקורות של ערוץ נכשלים מוצגת הודעה ברורה.
- **http בתוך אתר https:** דפדפנים חוסמים שידור `http://` בדף מאובטח. INDTV מדלג על מקורות כאלה ומציין זאת בהודעת השגיאה.
- **CORS:** בדפדפן מחשב (Chrome/Edge) שידורי HLS מתנגנים דרך hls.js, וזה דורש שהשרת של הערוץ יאפשר CORS. בטלוויזיות עם נגן HLS מובנה (Tizen, webOS, Safari) האתר עובר אוטומטית לנגן המובנה כש-hls.js נחסם.
- **Referer / User-Agent:** חלק מהערוצים ברשימה דורשים כותרות שדפדפן לא מאפשר לשנות. הם יופיעו אבל ייתכן שלא יתנגנו.
- hls.js נטען מ-jsDelivr והגופנים מ-Google Fonts, כך שהטלוויזיה צריכה חיבור לאינטרנט (שממילא נחוץ לשידורים).
- אין עקיפה של DRM, חומות תשלום, חסימות גאוגרפיות או התחברות.
